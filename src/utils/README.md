# Utilities (`utils`)

## Purpose

The `utils` directory contains small, reusable, framework-independent helper functions.

## Responsibilities

Utilities may include:

- Formatting
- Parsing
- Validation helpers
- Date/time utilities
- String manipulation
- File utilities
- General-purpose calculations
