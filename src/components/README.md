# Components (`components`)

## Purpose

The `components` directory contains reusable UI components shared across multiple features or pages of GameVerse.

## Responsibilities

Components may include:

- Buttons
- Inputs
- Modals
- Cards
- Dropdowns
- Tables
- Dialogs
- Loading indicators
- Error displays
- Navigation components
- Reusable form elements
