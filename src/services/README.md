# Services (`services`)

## Purpose

The `services` directory contains frontend clients responsible for communicating with backend services and external application interfaces.

## Responsibilities

Services may provide:

- REST API clients
- WebSocket clients
- Authentication API communication
- File upload communication
- Game service communication
- User service communication
- Notification communication
