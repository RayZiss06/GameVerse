# Routes (`routes`)

## Purpose

The `routes` directory contains the frontend routing configuration for GameVerse.

## Responsibilities

This directory defines:

- Application routes
- Route hierarchy
- Protected routes
- Public routes
- Authentication redirects
- Route-level boundaries
- Lazy-loaded routes where appropriate
