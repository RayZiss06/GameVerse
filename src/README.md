# Source (`src`)

## Purpose

The `src` directory contains the complete frontend source code for the GameVerse web application.

This directory is responsible for the presentation layer, client-side application logic, routing, state management, API communication, reusable UI, and frontend-specific utilities.

## Responsibilities

The `src` directory contains:

- Application configuration
- Reusable UI components
- Feature modules
- React hooks
- Page components
- Layouts
- Routing
- API and external-service communication
- Client-side state management
- Frontend TypeScript types
- Utility functions
- Static frontend assets
