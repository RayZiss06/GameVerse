# Hooks (`hooks`)

## Purpose

The `hooks` directory contains reusable React hooks that provide shared frontend behavior.

## Responsibilities

Hooks may handle:

- Browser APIs
- Application-level behavior
- Reusable React state logic
- Event listeners
- Media queries
- Network state
- Authentication state access
- Common UI behavior
