# Layouts (`layouts`)

## Purpose

The `layouts` directory contains structural layouts used to organize pages within the GameVerse application.

## Responsibilities

Layouts define common page structures such as:

- Public application layout
- Authenticated application layout
- Dashboard layout
- Admin layout
- Gaming/library layout

## Example Structure
