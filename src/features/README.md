# Features (`features`)

## Purpose

The `features` directory contains self-contained business features of the GameVerse frontend.

This is one of the most important organizational areas of the application.

## Responsibilities

Each feature should encapsulate its own:

- Components
- Hooks
- API interactions
- Types
- State
- Utilities
- Feature-specific logic

## Example Structure

```text
