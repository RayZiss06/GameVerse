# Docker

## Purpose

The `docker` directory contains Docker-related configuration used to run the GameVerse platform locally.

## Responsibilities

This directory manages:

- Docker Compose configuration
- Container definitions
- Local infrastructure networking
- Persistent container volumes
- Service health checks
- Container environment configuration
